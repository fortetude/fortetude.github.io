# Clearing the Sandbox

- Simply head to the overflow menu
- Tap on the (🗑️ **Clear**) option
  - ![clear](/assets/images/sandbox-clear.png)
- Confirm via dialog box
  - ![clear-confirm](/assets/images/sandbox-clear-confirm.png)
    
- The Sandbox will then be completely wiped!
