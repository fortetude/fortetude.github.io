# Saving Sandbox to a Line

This allows you to preserve your Line for another time, whilst working on other stuff in the Sandbox in the meantime.

- Tap on the save icon (💾) on the top-right
- A dialog box will appear prompting for the Line name
  - ![sandbox-save](/assets/images/sandbox-save.png)
- Add a suitable name and hit 'Save'

{: .warning}
> The app will enforce unique names by default !  
> - ![sandbox-save-error.png](/assets/images/sandbox-save-error.png)
