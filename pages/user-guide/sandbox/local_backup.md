# Performing a Local Backup

In case you need to move data to a new device, or reinstall the app later on.

## Exporting Data Locally

| Android 🤖 | iOS 🍎 |
| - | - |
| ![android1](/assets/images/export-android.png)<br/>Select **Export Data** | ![ios](/assets/images/ios-export.jpeg)<br/>Select **Export Data** |
| ![android2](/assets/images/export-android2.png)<br/>Grant permissions to Chrome if needed | ![ios2](/assets/images/ios-export2.jpeg)<br/> If in Safari, this prompt will appear, select **Download** - this will save to the **Downloads** folder |
| ![android2](/assets/images/export-android3.png)<br/>_same as above_ | ![ios3](/assets/images/ios-export3.jpeg)<br/> If in PWA, this prompt will appear, select **More...** |
| ![android2](/assets/images/export-android4.png)<br/>Download will automatically begin and save to the **Downloads** folder<br/><br/><br/>Note: this behaviour may be different on newer versions of Android! | ![ios4](/assets/images/ios-export4.jpeg)<br/>The usual Share menu will show up, **Save to Files** would be a good next step |

| Android 🤖 | iOS 🍎 |
| - | - |

| ![android2](/assets/images/import-android2.png)<br/>Select the file you want to import | ![ios2](/assets/images/ios-import2.jpeg)<br/>Select the file you want to import |
