# Shuffling the Sandbox

Useful for if you want to make things crazy with the same moves but in a different order.

- Simply head to the overflow menu
- Tap on the (🔀 **Shuffle**) option
  - ![shuffle](/assets/images/sandbox-shuffle.png)
- The Sandbox will now be randomly shuffled!
