# Importing a Line to the Sandbox

- Tap the folder icon (📁) in the top right
- A new search window will appear, which you can use to search exactly for a match
  - ![search-import](/assets/images/sandbox-import.png)
- Select the match
- Confirm if overwriting or appending the Sandbox.
    - ![sandbox-import-confirm](/assets/images/sandbox-import-confirm.png)
- The saved Line will then be successfully imported into the Sandbox.
