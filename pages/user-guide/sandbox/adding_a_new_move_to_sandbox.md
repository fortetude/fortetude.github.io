# Adding a Move to the Sandbox

{: .note}
You can also do this from the [Moves screen](/pages/user-guide/moves/adding_moves_to_sandbox).

- Tap on the plus icon (**+**) near the top-right
- A new search window will appear, which you can use to search exactly for a match
  - ![search-add](/assets/images/sandbox-add.png)
- Select the match and it will be added.
