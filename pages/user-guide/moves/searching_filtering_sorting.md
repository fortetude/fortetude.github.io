# Searching, Filtering and Sorting Moves

The full list of moves is quite long, so filtering and searching lets you quickly drill-down to only what you want to see; Sorting is also great for quickly identifying patterns and drawing conclusions based on the data.  

<details>
<summary>Simply tap the filter icon (▼) on the top-left to get started.</summary>  
    <img src="/assets/images/moves-drawer.png">  
</details>



---




## Searching Moves

- Simply input your keyword in the floating search bar (🔍) and all matches will appear.
- Searches operate on filtered results, so active filters will further constrain results.

![moves-search](/assets/images/moves-search.png)
  
## Filtering Moves

You can filter by all the expected fields such as:
- Category
  - ![moves-category](/assets/images/moves-category.png)
- Competency
  - ![moves-competency](/assets/images/moves-competency.png)
- Area of Concern
  - ![moves-aoc](/assets/images/moves-aoc.png)

## Sorting Moves

Sorting is done against:
- Category (default)
- Name in Ascending Order (A-Z)
- Name in Descending Order (Z-A)
- Overall rating (Low - High)
- Overall rating (High - Low)
