# Adding Moves to the Sandbox


{: .note}
You can also do this from the [Sandbox screen](/pages/user-guide/sandbox/adding_a_new_move_to_sandbox).

Simply tap on the button shown below, and the Move will be added to the Sandbox.

![adding-moves](/assets/images/moves-adding.png)

This action can be undone by tapping on the Undo button shown on the popup too!
