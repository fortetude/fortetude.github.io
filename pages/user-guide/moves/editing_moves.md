# Editing Move Properties

To edit a Move's properties, simply tap on the tile to bring up the bottom sheet:

| GIF                                        |                                          screenshot |
| ------------------------------------------ | --------------------------------------------------- | 
|![taptile](/assets/images/moves-taptile.gif)| ![taptile-static](/assets/images/moves-taptile.png) |

> To understand what all these values mean, head to the [rating](/pages/design#rating-system) section.

---

## Modifying Values


### Competency

![dropdown](/assets/images/moves-dropdown.gif)    
- A dropdown will appear which will allow you to choose from four options.

### Area(s) of Concern

![areas](/assets/images/moves-areas.gif)    
- For any Area(s) of Concern you are tackling with, simply select it.
- The button will appear selected and show as a warning icon (⚠️).

### Overall Control

![slider](/assets/images/moves-slider.gif)  
- Simply use the slider to change the value between 0-10.


## Saving changes

To save changes, simply tap the Save icon (💾) in the sheet's top right corner.
