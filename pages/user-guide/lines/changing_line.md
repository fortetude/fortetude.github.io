# Changing Line Items

## Editing Line Name
  
- Select a Line by tapping on its tile.
  <details>  
  <summary>Example</summary>  
  <img src ="/assets/images/lines-taptap.gif">
  </details>  
- Tap on the pencil icon (✏️) near the top-right to edit name
- ![edit](/assets/images/lines-edit.png)
- (The app will enforce unique names by default)


## Toggle Pin & Delete

| Toggle Pin                                     | Delete                                     |
| ---------------------------------------------- | ------------------------------------------ | 
| ![pin](/assets/images/lines-pin.png)           | ![delete](/assets/images/lines-delete.png) |
| Swipe right on tile to toggle pin/unpin status | Swipe left on tile to delete the Line      |
